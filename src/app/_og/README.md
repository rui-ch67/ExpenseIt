# Share-card font

`bricolage-grotesque-extrabold.ttf` is a static ExtraBold (96pt optical size) instance of
[Bricolage Grotesque](https://github.com/ateliertriay/bricolage), cut down to basic Latin so the
share card (`../opengraph-image.tsx`) can render offline at build time. The share card renderer
cannot read the variable `.woff2` file the app loads through `next/font`.
